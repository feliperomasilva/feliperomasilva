## 📌 Sobre este repositório

Este repositório reúne projetos desenvolvidos ao longo da minha jornada como programador, desde experimentos e projetos acadêmicos até aplicações mais estruturadas.

A ideia é centralizar meu trabalho em um único lugar, mantendo uma organização clara e uma documentação consistente para que qualquer pessoa consiga entender rapidamente **o que foi desenvolvido, quais tecnologias foram utilizadas e como cada projeto funciona**.

Atualmente estou cursando o técnico em **Análise e Desenvolvimento de Sistemas (ADS)** e construindo minha base para seguir na área de **Cibersegurança**, com interesse especial em **Pentest e Segurança Ofensiva**.

Este repositório acompanha essa evolução.
